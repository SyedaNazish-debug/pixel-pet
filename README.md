# 🐾 Pixel Pet Simulator

An interactive virtual pet game built with HTML, CSS and vanilla JavaScript.

Meet Pip, your pixel-art virtual pet! Feed, play with, clean and help Pip sleep while keeping its needs balanced.

Live Demo: "Play Pixel Pet Simulator" (https://syedanazish-debug.github.io/pixel-pet/)

Repository: "GitHub Source Code" (https://github.com/SyedaNazish-debug/pixel-pet)

---

About the Project

Pixel Pet Simulator is a browser-based project that explores interactive frontend development through a virtual pet experience.

Players interact with Pip using different care actions. Each action affects the pet's statistics, mood and expressions.

The project combines basic game logic, DOM manipulation, browser storage and visual feedback to create an interactive experience.

Features

- Four care actions: Feed, Play, Sleep and Clean.
- Pet statistics: Hunger, Happiness, Energy and Cleanliness.
- Dynamic expressions: Pip's appearance responds to its mood.
- Random interaction messages: Different responses during interactions.
- Visual animations: Interactive feedback for pet actions.
- Local storage: Saves pet progress in the browser.
- Responsive interface: Designed for different screen sizes.

Getting Started

Run Locally

Clone the repository:

git clone https://github.com/SyedaNazish-debug/pixel-pet.git

Navigate into the project:
```

cd pixel-pet
```

Open "index.html" in your browser, or use the VS Code Live Server extension.
```

Run Tests
```

Make sure Node.js is installed, then execute:
```

node test-pixel-pet.js
```
